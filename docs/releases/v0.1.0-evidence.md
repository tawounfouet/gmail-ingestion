## Large-mailbox hardening

A real qualification attempt against a mailbox containing more than 177k messages exposed
avoidable control-state overhead. The release candidate was hardened before stable publication:

```text
durable nextPageToken checkpoint          PASS
resume discovery from exact cursor        PASS
bounded hydration futures                 PASS
batched discovery-state persistence       PASS
bounded real qualification sample         PASS
full snapshot default unchanged           PASS
```

The normal `gmail-ingest snapshot` command remains a full-mailbox snapshot. The live qualification
script deliberately uses bounded samples so release qualification does not require exporting the
entire mailbox.

## Attachment portability hardening

A real `has:attachment` qualification exposed Gmail attachment IDs long enough to exceed macOS
filesystem filename limits when copied verbatim into storage names.

The stable candidate now uses short deterministic SHA-256-derived physical filenames while retaining
the original message ID, attachment ID, filename and source URI in metadata.

Regression coverage includes an attachment ID longer than 600 characters.
