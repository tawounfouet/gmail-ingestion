# Gmail Ingestion 0.3.0 — Search / Date Range / Filtered Ingestion

## Status

**Stable release — qualification complete.**

The implementation preserves the stable `0.2.0` normalized schema and changes only which Gmail
messages are selected during discovery.

## Capability

```text
Explicit filter request
   ↓
GmailFilter / DateRange
   ↓
canonical + frozen scope
   ↓
users.messages.list
   ↓
q + labelIds + includeSpamTrash
   ↓
existing hydration / RAW pipeline
   ↓
existing Normalized Dataset v1
```

Supported scopes:

```text
full snapshot
query snapshot
label-filtered snapshot
absolute date range
relative last N days
combined query + labels + dates
```

## Stable contract

```text
normalized_schema_version = 1
OAuth scope               = gmail.readonly
RAW semantics             = unchanged
message hydration         = format=full
stateful Gmail History    = not introduced
```

## Scope identity

The manifest records both the user request and the effective Gmail request:

```text
requested_filter
effective_filter
scope.kind
scope.fingerprint
```

Relative dates are resolved once at run start and remain frozen across resume.

## CLI

```bash
gmail-ingest snapshot --query "has:attachment"
gmail-ingest snapshot --label-id IMPORTANT

gmail-ingest range --after 2026-10-01 --before 2026-10-24
gmail-ingest range --last-days 7
```
