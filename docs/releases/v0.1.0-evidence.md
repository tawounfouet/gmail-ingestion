## Large-mailbox hardening

A real package execution against a mailbox with more than 177k messages was manually interrupted
after confirming real RAW writes. That observation exposed avoidable control-state overhead and led
to the following release hardening:

```text
durable nextPageToken checkpoint          PASS
resume discovery from exact cursor        PASS
bounded hydration futures                 PASS
batched discovery-state persistence       PASS
50-message live qualification sample      PASS (automated contract)
full snapshot default unchanged           PASS
```

The normal `gmail-ingest snapshot` command remains a true full-mailbox snapshot. The release gate
script uses `mode=sample_snapshot` with a bounded sample by default so a large personal mailbox
does not need to be fully downloaded merely to qualify source integration.
