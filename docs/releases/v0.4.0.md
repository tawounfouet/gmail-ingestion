```text

    ↓
users.history.list
    ↓

    ↓

    ↓

    ↓

    ↓

    ↓
```

Missing or expired cursors recover through:

```text
Full Snapshot
→ COMPLETED only
→ bootstrap checkpoint
→ History catch-up
→ committed incremental baseline
```

## Reliability behavior

- frozen History pages are reused on same-run restart;
- PROCESSED events are not reduced twice;
- durable receipts prevent cross-run effect repetition;
- already persisted full-message RAW is reused;
- stale checkpoint promotion/invalidation is rejected by compare-and-swap;
- a completed snapshot/bootstrap can resume directly at History catch-up;
- a malformed individual Gmail MIME header is ignored with a warning instead of failing the message;
- an added message that is already permanently deleted at hydration time is treated as unavailable
  rather than aborting the History window.
