## RC3 race invariant

Gmail may expose a `MESSAGE_ADDED` event whose message is already permanently unavailable when
the connector attempts hydration.

RC3 permits a missing RAW only when a later delete in the same deterministic projected chain proves
that the target Current State must not contain the message:

```text
MESSAGE_ADDED without RAW
        +
later MESSAGE_DELETED for same message
        ↓
safe no-op for unavailable add
        ↓
delete reducer
        ↓
target Current State excludes message
```

Without the later matching delete:

```text
MESSAGE_ADDED without RAW
        ↓
FAIL CLOSED
```

## Stable promotion-only rule

Once the live gate passes, promotion from `0.5.0rc3` to `0.5.0` may change only:

- package version / release metadata;
- release documentation;
- CI artifact naming where needed;
- tests that explicitly assert the prerelease version.

No projection semantic, schema, reducer, persistence or recovery change is allowed after the
live-qualified RC3 candidate without producing another release candidate.
