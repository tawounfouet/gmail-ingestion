# Gmail Ingestion 0.1.0 — Snapshot Foundation Stable

## Status

**Stable Snapshot Foundation.**

This release freezes the first complete Gmail source-ingestion foundation. It is intentionally
pre-analytics: normalized message/thread datasets begin in 0.2.0.

## Stable capability

```text
OAuth Desktop
  → Profile
  → Labels
  → paginated message discovery
  → users.messages.get(format="full")
  → immutable RAW
  → recursive MIME
  → attachment metadata
  → optional binary attachment storage
  → manifest v1
  → resumable snapshot
```

## Reliability

- bounded concurrent hydration;
- bounded retry;
- durable discovery queue;
- resume without duplicate RAW;
- attachment failures surfaced as structured partial errors;
- SHA-256 for downloaded attachments;
- no OAuth token material in ingestion artifacts;
- strict account identity verification.

## Compatibility

- Python 3.11, 3.12 and 3.13;
- PyIngestKit v2.1.0;
- Gmail API v1;
- exact `gmail.readonly` OAuth scope.

## Qualification

Automated RC qualification covers empty mailbox, text, HTML, multipart, threads, attachment
download, retry, token refresh and a 1,001-message / three-page sample.

Stable publication additionally requires a real Gmail test-mailbox pass through the package's own
OAuth and API client path.

## Next milestone

`0.2.0 — Normalized Dataset` introduces stable analytical tables for accounts, labels, messages,
threads, headers, recipients, message-label relations, MIME parts and attachments.
