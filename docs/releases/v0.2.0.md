# Gmail Ingestion 0.2.0 — Normalized Dataset Stable

## Status

**Stable normalized analytical contract.**

This release keeps the `0.1.0` source snapshot semantics unchanged and introduces the first
versioned Gmail normalized schema.

## Stable capability

```text
0.1.0 Snapshot Foundation
   ↓
RAW Gmail payloads
   ↓
normalize_snapshot()
   ↓
accounts / labels / messages / threads
headers / recipients / message_labels
mime_parts / attachments
   ↓
quality gates
   ↓
deterministic Parquet
```

## Schema contract

```text
normalized_schema_version = 1
```

Each table has an explicit grain, logical key and typed field contract. Gmail source identifiers are
preserved, UTC timestamps are explicit, and multi-valued fields use canonical relation tables.

## Determinism

For the same RAW payloads, normalization timestamp, dataset version and connector version, the
logical normalized output is reproducible. Qualification writes Parquet twice and reloads both
outputs to verify logical equality.

## Quality gates

- required non-null fields;
- logical primary-key uniqueness;
- message/thread relationship;
- headers/recipients/MIME/attachments → message references;
- message-label → message and label references;
- non-negative attachment size;
- downloaded attachment requires storage URI and SHA-256;
- normalized schema version must be `1`.

## Compatibility

- Python 3.11, 3.12 and 3.13;
- PyIngestKit v2.1.0;
- Gmail API v1 source layer inherited from 0.1.0;
- exact `gmail.readonly` scope remains unchanged.
