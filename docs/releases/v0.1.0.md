# Gmail Ingestion 0.1.0 — Snapshot Foundation Stable

## Status

**Stable Snapshot Foundation.**

This release freezes the first complete Gmail source-ingestion foundation. It is intentionally
pre-analytics: normalized message/thread datasets begin in 0.2.0.

## Stable capability

```text
OAuth Desktop
  → Profile
  → Labels
  → paginated message discovery
  → users.messages.get(format="full")
  → immutable RAW
  → recursive MIME
  → attachment metadata
  → optional binary attachment storage
  → manifest v1
  → resumable snapshot
```

## Reliability

- bounded concurrent hydration;
- bounded retry;
- durable discovery queue with persisted Gmail page cursor;
- bounded in-flight hydration and batched state checkpoints;
- resume without duplicate RAW;
- attachment failures surfaced as structured partial errors;
- SHA-256 for downloaded attachments;
- short deterministic attachment storage names safe for long Gmail attachment IDs;
- no OAuth token material in ingestion artifacts;
- strict account identity verification.

## Compatibility

- Python 3.11, 3.12 and 3.13;
- PyIngestKit v2.1.0;
- Gmail API v1;
- exact `gmail.readonly` OAuth scope.

## Qualification

Automated stable qualification passes 43/43 tests on Python 3.11, 3.12 and 3.13.

The package's own real Gmail Desktop OAuth E2E also passed on 2026-10-25:

- 137 labels ingested;
- 50/50 real messages fetched;
- 50/50 MIME payloads processed;
- manifest completed;
- same-run resume detected with stable counts;
- targeted `has:attachment` sample fetched 10/10 attachments;
- 816,892 bytes downloaded;
- zero attachment failures;
- OAuth secrets absent from generated ingestion artifacts.
