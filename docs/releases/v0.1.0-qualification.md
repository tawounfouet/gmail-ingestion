## Real Gmail release gate

A real Gmail mailbox must be authorized with the package's own Desktop OAuth flow. The gate uses
a bounded sample by default so it is safe to run against a large mailbox:

```bash
gmail-ingest auth
gmail-ingest profile
python scripts/qualify_live_snapshot_foundation.py \
  --sample-size 50 \
  --download-attachments \
  --require-attachment \
  --max-attachment-bytes 10485760
```

The script exercises the production snapshot path with `mode=sample_snapshot`; the normal
`gmail-ingest snapshot` command remains an unbounded full-mailbox snapshot. The script emits only
redacted evidence. It does not write email addresses, OAuth access tokens,
refresh tokens or the client secret into the evidence JSON.

Required result:

```text
live_gate: PASS
```

## Publication rule

Only a release-branch head with both automated CI PASS and real Gmail live gate PASS may be merged
to `main`.

After merge, the exact merge SHA must pass CI again. Only that exact SHA is eligible for
`v0.1.0` and the stable GitHub release.
